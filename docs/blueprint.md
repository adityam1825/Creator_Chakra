# **App Name**: CreatorMind AI

## Core Features:

- Multimodal Content Lab: An AI generation tool that produces high-performance copy across Instagram, LinkedIn, and Twitter using reasoning to adapt tone and length.
- Virality Prediction Score: Predictive analytics tool that evaluates content using AI to provide a score out of 100 based on predicted engagement and emotional impact.
- Content Critique & AI Judge: An AI-powered reviewing tool that analyzes user text for grammar, clarity, and SEO, offering direct improvement suggestions and 'Before vs. After' previews.
- Strategic Repurposing Engine: AI tool that reasonings through long-form transcripts or articles to intelligently split and reformulate them into bite-sized social media formats.
- Global Culture Mode: Multi-language generation supporting Hindi, Spanish, and more, including cultural nuances and local trend adaptation via AI.
- Intelligent Content Planner: An interactive calendar interface with AI-driven posting recommendations based on platform-specific audience activity heatmaps.
- Scalable Persistence Layer: Robust data storage for project history, analytics, and user settings powered by a PostgreSQL database and Prisma ORM.

## Style Guidelines:

- A sophisticated dark-themed palette. Primary color: Vivid Indigo-Purple (#8B5CF6) symbolizing intelligence and creativity. Background: Deep Onyx (#121019) to create a premium focus. Accent: Electric Cobalt (#3B82F6) for critical calls to action.
- Font pairing: 'Space Grotesk' for tech-forward headlines that feel scientific yet stylish, and 'Inter' for highly legible dashboard UI and dense blocks of content.
- Custom ultra-thin line icons with subtle purple glows and semi-transparent backings, matching the premium glassmorphism aesthetic.
- Modern sidebar-driven dashboard with high-contrast sections and wide whitespace; utilizing 'Notion-like' clarity with 'Framer' visual polish.
- Liquid-smooth transitions powered by Framer Motion, featuring spring-physics sidebar expansion and staggered entries for AI data cards.
